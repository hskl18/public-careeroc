# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its standards apply in issues, pull requests, reviews, and every other project space.

Report unacceptable behavior privately to the maintainer, through the contact details on the [maintainer's GitHub profile](https://github.com/hskl18).
Reports are kept confidential, and the maintainer decides on any action under the Covenant's enforcement guidelines.
